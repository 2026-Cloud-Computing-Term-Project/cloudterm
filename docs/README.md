# Docs

프로젝트 문서 인덱스다.

| 문서 | 목적 |
| --- | --- |
| `docs/project-status.md` | 팀 개발 시작 가이드 기준 완료 현황과 역할별 다음 작업 |
| `docs/team-development-guide.md` | 브랜치 전략, 역할 분담, PR 규칙, 구현 범위 |
| `docs/api-contract.md` | HTTP/WebSocket/Runner API 계약 |
| `docs/deliverables/` | 제안서, 중간보고서, 최종보고서 PDF(`report.pdf`), 발표자료, 아키텍처 다이어그램 |
| `docs/templates/` | 수업 제공 양식과 공지 원본 |

팀원이 처음 보는 문서는 루트 `README.md`이고, 실제 작업 판단은 `docs/project-status.md`를 기준으로 한다.
